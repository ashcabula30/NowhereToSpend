# NowhereToSpend

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Vercel-blueviolet?style=for-the-badge&logo=vercel)](https://nowheretospend.vercel.app)
[![SaaS](https://img.shields.io/badge/Product-SaaS%20Platform-blue?style=for-the-badge)](https://github.com/ashcabula30/NowhereToSpend)
[![Mobile](https://img.shields.io/badge/Platform-iOS%20%26%20Android-green?style=for-the-badge&logo=react)](https://github.com/ashcabula30/NowhereToSpend)

> A premium, cloud-powered personal budget tracking and financial intelligence application. Built on a cutting-edge mobile-first stack with an integrated intelligent finance adviser chatbot.

---

## ✨ Features Highlight

- **🤖 Sova AI Insights**: A highly intelligent, intent-based conversational finance adviser providing personalized budgeting and savings strategies.
- **📊 Dynamic Financial Dashboard**: Beautiful real-time tracking of current, pending, and projected savings with sleek, interactive charts.
- **🏦 Unified Account Management**: Consolidate and monitor balances across multiple bank accounts and custom financial categories.
- **📈 Advanced Expense Planning**: Commission tracking, monthly fixed expense oversight, and flexible goal-setting utilities.
- **🛍️ Affordability Simulator**: A smart wishlist playground that simulates purchases against your real-time budget, telling you exactly when and how you can afford what you want.
- **🎨 Premium UX/UI**: Designed with a high-fidelity SaaS aesthetic, gorgeous dark-mode-first interfaces, and buttery smooth animations.

---

## 🛠️ The Technology Stack

This application is built with modern, enterprise-grade frameworks optimized for performance and cross-platform compatibility:

- **Frontend Core**: [Expo](https://expo.dev/) & [React Native](https://reactnative.dev/) (TypeScript)
- **Navigation Engine**: [Expo Router](https://docs.expo.dev/router/introduction/) (Next-generation file-based routing)
- **Database & Auth**: [Supabase](https://supabase.com/) (PostgreSQL engine + Real-time sync + Row Level Security)
- **Global State**: [Zustand](https://github.com/pmndrs/zustand)
- **Styling Architecture**: [NativeWind](https://www.nativewind.dev/) (Tailwind CSS engine for native devices)
- **Fluid Motion**: [React Native Reanimated](https://docs.swmansion.com/react-native-reanimated/) + [Moti](https://moti.fyi/)
- **Data Visualizations**: [React Native Chart Kit](https://github.com/indri/react-native-chart-kit)
- **Infrastructure**: Ready for deployment to **Vercel** and **Azure Static Web Apps**.
